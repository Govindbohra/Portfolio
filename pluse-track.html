Pluse Track

Enterprise Dashboard · UI/UX Case Study

Overview

Pluse Track is a global sentiment tracking dashboard designed for enterprise clients. The goal was to transform fragmented, siloed data into actionable insights for decision-makers across multiple regions and business units.

Problem

  • Enterprise clients struggled with scattered data sources and inconsistent reporting.
  • Decision-makers lacked a unified view of global sentiment and trends.
  • Existing tools were not user-friendly and required manual data wrangling.

Solution

  • Designed a visually cohesive dashboard with real-time data integration.
  • Created custom data visualizations for sentiment, trends, and KPIs.
  • Implemented role-based access and personalized views for different user types.
  • Ensured accessibility and mobile responsiveness for all users.

Process

  • Conducted stakeholder interviews and user research to define requirements.
  • Mapped user journeys and pain points.
  • Developed wireframes and interactive prototypes in Figma.
  • Iterated designs based on usability testing and feedback.

Impact

  • Reduced reporting time by 60% for business analysts.
  • Increased dashboard adoption rate to 95% within 3 months.
  • Enabled leadership to make faster, data-driven decisions.

Key Screens

  • Global Sentiment Overview
  • Trend Analysis & Drilldowns
  • Custom Alerts & Reports
  • User Management & Settings

Tools Used

  • Figma, Adobe XD, Power BI, D3.js, Google Analytics

My Role

  • Led end-to-end UX design and research
  • Collaborated with data engineers and product managers
  • Presented solutions to C-suite and global stakeholders
